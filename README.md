# 👤 Face Recognition App

A simple **Machine Learning** powered **Face Recognition Web App** built with **Streamlit**.  
Upload an image, and the app will predict which friend it is based on the trained model.

---

## 📌 Features
- 📷 Upload an image (JPG/PNG)
- 🔍 Detect & recognize faces
- 🤖 Machine Learning model trained on custom dataset
- 🌐 Deployable on **Streamlit Cloud**

---

## 🛠 Tech Stack
- **Python 3.x**
- **Streamlit** – Web interface
- **OpenCV** – Image processing
- **Scikit-learn** – Model training
- **Pickle** – Model saving/loading
- **NumPy & Pandas** – Data handling
- **Matplotlib** – Visualizations (optional)

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository
```bash
git clone https://github.com/your-username/face-recognition-app.git
cd face-recognition-app
```
2️⃣ Install dependencies
```bash

pip install -r requirements.txt
```
3️⃣ Run the app locally
```bash

streamlit run app.py
```
